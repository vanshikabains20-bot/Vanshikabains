Question 1 — Computer Characteristics & Generations

A modern digital computer has several important characteristics:

1. High speed — It can process millions or billions of instructions in a short time.

2. Accuracy — When the input, program and instructions are correct, the computer produces accurate results.

3. Storage capacity — It can store large amounts of programs, data and results and retrieve them quickly.

4. Automation and consistency — Once a program is started, the computer can perform repetitive operations automatically and consistently.

The five generations of computers are associated with these major hardware technologies:

  • First generation: Vacuum tubes.
  • Second generation: Transistors.
  • Third generation: Integrated Circuits (ICs).
  • Fourth generation: Microprocessors using very-large-scale integration (VLSI).
  • Fifth generation: Advanced VLSI/ULSI-based systems with increasing emphasis on parallel processing, AI and intelligent computing.

Thus, computer generations show the development from large, heat-producing vacuum-tube machines to compact, powerful and intelligent modern systems.

Question 2 — Block Diagram & System Architecture

The functional block diagram of a computer can be understood through four major parts: Input Unit, CPU, Memory Unit and Output Unit.

Data and instructions are first entered through an input device such as a keyboard, scanner or other I/O interface. The input unit converts them into a form the computer can process. The data and instructions are then placed in memory.

The CPU controls and processes the information. The Control Unit (CU) fetches instructions from memory, decodes them and sends control signals to the appropriate components. The Arithmetic Logic Unit (ALU) performs arithmetic and logical operations. Registers provide very fast temporary storage during processing.

The memory unit stores programs, input data, intermediate results and final results. The CPU continuously exchanges data and instructions with memory through buses.

After processing, the result is sent through the I/O interface to an output device such as a monitor, printer or speaker. Therefore, the overall flow is:

Input → Memory ↔ CPU (Control Unit + ALU + Registers) → Output

Control signals coordinate the movement and processing of data so that every component performs its required operation at the correct time.

Question 3 — Scanning & Card Reading in a Campus

A campus can automate attendance and library checkouts by combining optical scanning devices with electronic card readers.

For attendance, each student can be given a barcode/QR identification or an ID card containing machine-readable information. At the entrance, a barcode or optical scanner reads the student's code. The system sends the identifier to the campus database, verifies the student record and records the date and time automatically.

OMR-style scanning can also be used where specially designed forms are required, for example for attendance sheets or surveys. The scanner detects marked positions and transfers the information to software.

For the library, RFID cards/tags or smart cards can be used. A student presents the card at the library desk or near an RFID reader. The reader obtains the student's identification electronically. The library system checks the account, records the book issue/return transaction and updates the database.

Benefits include faster processing, fewer manual errors, automatic record keeping and easier tracking of attendance and books.

Question 4 — Low-Level vs High-Level Languages

Low-level languages are closely related to computer hardware. Machine language consists of binary instructions that the processor can execute directly. Assembly language uses symbolic mnemonics and requires an assembler to translate it into machine code.

High-level languages use English-like syntax and higher-level programming concepts. They require a compiler or interpreter (depending on the language and execution model) to translate or execute the program.

Comparison:

  • Execution speed: Machine code is executed directly and can be very fast. Assembly can also produce efficient machine-level programs. High-level programs may involve additional translation/runtime mechanisms, although modern compilers can produce highly optimized code.
  • Hardware dependence: Machine and assembly languages are strongly hardware/processor dependent. High-level languages are generally more portable.
  • Translation: Machine language needs no further translation by an assembler/compiler for execution. Assembly requires an assembler. High-level languages require a compiler, interpreter or related runtime process.
  • Programming complexity: Machine language is the most difficult and error-prone. Assembly is easier than machine code but still complex. High-level languages are generally easier to learn, develop and maintain.

Therefore, low-level languages provide close hardware control, while high-level languages emphasize programmer productivity and portability.

Question 5 — Point-and-Draw Devices vs Graphics Digitizers

A mouse and a trackball are point-and-draw devices mainly used to control a screen pointer. A mouse is moved across a surface and its sensor detects relative movement. A trackball remains in a fixed position while the user rotates a ball to control pointer movement.

A graphics digitizer or drawing tablet is designed for precise coordinate input. It can detect the position of a stylus on a dedicated surface and can provide much finer control than a normal mouse for drawing and CAD work. Many modern tablets also detect pressure, allowing the thickness, opacity or intensity of a digital stroke to change according to how hard the user presses.

For CAD, precise coordinate tracking is important for creating accurate lines, shapes and technical drawings. For digital art, pressure sensitivity is especially useful because it can imitate natural pen or brush behaviour.

In short, mouse/trackball devices are general-purpose pointing devices, while digitizers are specialized precision input devices suited to CAD, illustration and other coordinate-sensitive applications.

Question 6 — Plotter vs UHD Monitor + Large-Format Printer

For producing civil engineering blueprints, a large-format printing solution using a high-resolution monitor together with a large-format printer is generally the more practical choice.

A drum or flatbed plotter can provide accurate line drawing and has traditionally been useful for engineering drawings. However, modern large-format printers can produce high-resolution technical documents, colour drawings and multiple document types, while a UHD monitor provides detailed on-screen inspection before printing.

Line resolution is important because engineering drawings contain fine lines, dimensions and annotations. A modern large-format printer can provide high-quality output when an appropriate technical-paper and print setting is selected.

Scalability is another advantage. A printer-based workflow can support different paper sizes and can be integrated with CAD software and digital document management. It also allows repeated production of drawings without the mechanical limitations of older plotting systems.

For long-term cost, the final choice depends on purchase price, consumables, maintenance, workload and required accuracy. For a modern campus or engineering office, the UHD-monitor plus large-format-printer combination is generally preferable because it provides a flexible digital workflow and supports both inspection and final production.

Question 7 — Facial Recognition vs Voice Recognition

In a high-ambient-noise and publicly exposed environment, both facial and voice recognition have advantages and security limitations.

Facial recognition is generally less affected by ambient sound because it uses visual features. However, its reliability can be affected by lighting, camera position, occlusion, masks, changes in appearance and image quality. In a public location, cameras may also create privacy concerns. Spoofing attempts using photographs, videos or other presentation attacks are security considerations, so liveness or presentation-attack detection is important.

Voice recognition is strongly affected by environmental noise. In a high-noise environment, the microphone may capture speech poorly, reducing recognition accuracy. A person's voice can also change because of illness, stress or background conditions. Voice systems may face replay or recorded-audio attacks unless additional anti-spoofing measures are used.

For a primary biometric authentication system in a publicly exposed, noisy environment, facial recognition with strong liveness detection is often more practical than voice recognition because it is not directly dependent on acoustic conditions. However, neither should be treated as automatically secure. Multi-factor authentication, encryption, access controls, liveness/anti-spoofing measures and secure biometric storage should be used where security requirements are high.

Question 8 — Accessible Hands-Free Workstation

An accessible workstation for a visually impaired user should combine non-visual input with specialized output.

Input system:

  • A voice-recognition microphone allows the user to enter commands and dictate text.
  • A tactile keyboard with clearly distinguishable keys provides reliable physical input.
  • Keyboard shortcuts reduce dependence on mouse-based navigation.

Processing and software:

  • A computer with an operating system's accessibility features enabled.
  • A screen reader converts on-screen text, menus and notifications into speech.
  • Voice-control software can open applications, type commands and navigate supported interfaces.

Output system:

  • A voice-response synthesizer or text-to-speech system provides audible feedback.
  • Headphones or a suitable speaker can deliver speech output.
  • A refreshable Braille display can be added when tactile reading of text is required.

A simple workflow is:

Voice/Tactile Input → Computer & Accessibility Software → Screen Reader/Text-to-Speech → Audio Output

The workstation should also provide adjustable volume, keyboard accessibility, clear system feedback, shortcut keys and secure user authentication. This integrated design allows the user to operate the computer with minimal dependence on visual information and supports both productivity and accessibility.
